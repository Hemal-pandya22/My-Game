# 🎮 My-Game

A fun and interactive browser-based game built using **HTML, CSS, and JavaScript**.

## 🕹️ About the Game

**My-Game** is a simple web-based game created as a programming project to practice front-end development and JavaScript game logic.

The game runs directly in a web browser, so no additional software or installation is required.

## ✨ Features

- 🎮 Interactive gameplay
- 🖥️ Runs directly in a web browser
- ⚡ Fast and lightweight
- 🎨 Simple and user-friendly interface
- 💻 Built with web technologies
- 🔄 Easy to modify and improve

## 🛠️ Technologies Used

- **HTML5** – Structure of the game
- **CSS3** – Styling and layout
- **JavaScript** – Game logic and interactions

## 🚀 How to Run

### Method 1: Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `game.html`.
4. The game will open in your web browser.
5. Start playing! 🎮

### Method 2: Using VS Code

1. Open the repository in **Visual Studio Code**.
2. Open `game.html`.
3. Use **Live Server** to launch the game in your browser.
